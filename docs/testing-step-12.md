## Step 12 — Diagnostics

현재 DB 상태를 별도 processing state 없이 즉석 집계한다.

### 표시

- 전체 사진
- 원본 GPS / 추정 GPS / GPS 없음
- 분류 완료 / 미분류
- 미확정 POI
- 확정 사진
- Visit / Place / 기록 날짜 수
- category별 사진 수

### 테스트

1. 처음 import 직후 `사진`, `원본 GPS`, `GPS 없음` 합계가 실제 import 결과와 대체로 맞는지 확인한다.
2. SigLIP2 분류 후 `분류 완료`가 증가하고 `미분류`가 줄어드는지 확인한다.
3. GPS 추정 후 `추정 GPS`가 증가하고 `GPS 없음`이 줄어드는지 확인한다.
4. 장소 관련 사진이 분류되면 `미확정 POI`가 늘어나는지 확인한다.
5. Place를 확정하면 `미확정 POI`가 줄고 `확정 사진`, `Visit`, `Place`가 갱신되는지 확인한다.
6. 확정을 해제하면 숫자가 반대로 되돌아오는지 확인한다.
7. 각 작업 후 수동 새로고침 없이 Diagnostics가 자동 갱신되는지 확인한다.

이 패널은 실제 첫 테스트에서 파이프라인이 어느 단계까지 정상 동작했는지 빠르게 확인하기 위한 용도다.
